# VirusTotal Scanner (vt-scanner)

Высокопроизводительный консольный сканер файлов на вирусы, написанный на Go. Утилита использует VirusTotal API (v3) для глубокого сканирования как одиночных файлов, так и целых директорий, а также архивов "на лету" прямо в оперативной памяти.

## Основные возможности
- **Потоковое сканирование архивов (In-Memory Streaming):** Программа читает и вычисляет хеши файлов внутри архивов `.zip`, `.tar.gz`, `.iso` и `.rar` (включая RAR5) напрямую в оперативной памяти. Ни один файл из архива не извлекается на жесткий диск.
- **Умная фильтрация (Smart Filtering):** Автоматически пропускает безопасные форматы файлов (изображения, видео, шрифты, конфиги), экономя лимиты API и сокращая время сканирования игровых директорий с часов до минут.
- **Параллелизм и Rate-Limit:** Использует пул воркеров для параллельной обработки файлов, при этом строго соблюдая лимиты бесплатного тарифа VirusTotal (не более 4 запросов в минуту).
- **Рекурсивный обход директорий:** Сканирует все вложенные папки.
- **Сводный отчет:** Генерирует единый, аккуратный `vt_scan_report.json` со статусом всех просканированных файлов.

## Установка

Убедитесь, что у вас установлен Go (версии 1.20+), склонируйте репозиторий и соберите проект:

```bash
git clone <ваш-репозиторий>
cd vt-scanner
go mod tidy
go build -o vt-scanner.exe ./cmd/vt-scanner
```

## Настройка

Для работы программы требуется API ключ VirusTotal. Создайте файл `.env` в корне проекта (рядом с исполняемым файлом) и добавьте туда ваш ключ:

```env
VT_API_KEY="ваш_ключ_virustotal"
```

## Использование

Сканирование одиночного файла или архива:
```powershell
.\vt-scanner.exe -file "C:\Downloads\Game.rar"
```

Рекурсивное сканирование папки:
```powershell
.\vt-scanner.exe -dir "C:\Games\MyGame"
```

Сканирование архива с паролем:
```powershell
.\vt-scanner.exe -file "C:\Downloads\Encrypted.rar" -password "12345"
```

### Доступные флаги
- `-file` — Путь к одиночному файлу или архиву для сканирования.
- `-dir` — Путь к директории для рекурсивного сканирования.
- `-env` — Путь к файлу конфигурации (по умолчанию `.env`).
- `-upload-new` — Автоматически загружать файлы на сервера VT, если их хеш не найден в базе (Не рекомендуется для огромных директорий из-за лимитов бесплатного API).
- `-password` — Пароль для расшифровки запароленных архивов.
- `-json` — Генерировать JSON отчет в дополнение к консольному выводу (по умолчанию `.vt_scan_report.json`).
